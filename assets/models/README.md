# ローカルモデル

このディレクトリには、MikuMikuDayoのLinux/AMD動作確認用に、配布元から取得したモデルを置きます。
モデル本体・テクスチャ・アーカイブは各作者の規約に従い、Gitへ登録・再配布しません。

## 取得済み

- **初音ミク**: [Tda式初音ミク デフォ服ver / BowlRoll #16344](https://bowlroll.net/file/16344)
  - ローカル: `miku/model/miku.pmx`
  - 作者: Tda / 金子卵黄
- **重音テト**: [Tda式重音テトTypeS / BowlRoll #11308](https://bowlroll.net/file/11308)
  - ローカル: `teto/model/teto.pmx`
  - 作者: Tda / やまもと（ReYaMa）

使用時は各アーカイブのREADMEと、[重音テト公式ガイドライン](https://kasaneteto.jp/guidelines/)を確認してください。
