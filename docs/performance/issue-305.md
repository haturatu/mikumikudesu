# #305: 評価スナップショットの名前を保持する

毎フレームmodelsをclearして名前リストを作り直す方式から、各スロットの所有データを更新する方式へ変更した。
不変なpath、表示名、モデル名、ボーン名、モーフ名は値が変わった場合だけ代入する。
サイズ変更と値比較により同じモデルオブジェクト上のrenameやreloadにも追従し、世代通知への依存を避ける。
モデルIDと順序も毎回更新し、公開しなくなった末尾スナップショットを除去する。

ボーン姿勢とモーフウェイトは引き続き毎フレーム更新する。
Previewの顔・目・ボーン追従とnativeコントローラで同じ評価結果を利用する。
非同期ピックが保持するスナップショットもあるため、名前をstring_viewへ変更せず所有権を維持する。

検証: SSOを超える長い名前の保存領域維持、rename、reload、個体置換、名前の削除、コピー済みスナップショットの独立性。
既存の顔・目・ボーン/コントローラテストとアプリのモデル追加削除テストも実行する。
文字列比較そのものは残る。FPS・時間短縮率は未計測で、名前文字列の再生成・毎フレームの破棄を除いた変更として採用する。
